# Как собрать APK с телефона через GitHub Actions

Компиляция (и Kotlin-часть, и Go-ядро Xray-core) идёт не на телефоне,
а на бесплатном облачном сервере GitHub. С телефона нужно только
загрузить код и потом скачать готовый APK — займёт 10-15 минут ожидания
сборки, без единой команды в терминале.

## Шаг 1. Завести репозиторий на GitHub (с телефона)

1. Установи приложение **GitHub** (Google Play / App Store) или просто
   открой github.com в браузере телефона и залогинься.
2. В приложении: **+** → **New repository**.
   - Name: `VlessHub`
   - Public или Private — не важно, оба варианта поддерживают Actions
     бесплатно (у Private есть лимит минут в месяц, но для таких сборок
     этого более чем достаточно).
   - **Не** добавляй README/gitignore при создании — просто пустой репозиторий.

## Шаг 2. Загрузить файлы проекта

Мобильное приложение GitHub, к сожалению, не умеет заливать zip и
распаковывать структуру папок — для этого удобнее веб-интерфейс
в браузере телефона:

1. Разархивируй `VlessHub.zip` любым файловым менеджером с телефона
   (встроенный "Files" на Android умеет).
2. Открой в браузере `github.com/<твой_логин>/VlessHub`.
3. Нажми **Add file → Upload files**.
4. Браузеры на телефоне обычно позволяют выбрать сразу **папку** через
   выбор файлов (Chrome/Firefox на Android — да). Если появится только
   выбор отдельных файлов — залей файлы по подпапкам вручную
   (`.github/workflows/build.yml`, `app/build.gradle.kts` и т.д.) —
   дольше, но так тоже сработает.
5. Внизу страницы — **Commit changes** прямо в `main`.

### Альтернатива — Termux + git (быстрее для повторных апдейтов)

Если один раз настроишь Termux, дальше заливать правки будет удобнее:

```bash
pkg install git
cd storage/downloads   # где лежит распакованный VlessHub
git init
git remote add origin https://github.com/<логин>/VlessHub.git
git add .
git commit -m "initial"
git branch -M main
git push -u origin main
# попросит логин и Personal Access Token вместо пароля
# (создаётся в GitHub: Settings → Developer settings → Personal access tokens)
```

## Шаг 3. Запустить сборку

Как только файлы запушены в `main` — workflow `.github/workflows/build.yml`
запустится **автоматически** (там есть триггер `on: push`).

Проверить статус:
1. Открой репозиторий на github.com (или в приложении) → вкладка **Actions**.
2. Увидишь запуск "Build VlessHub" с жёлтым кружком (идёт) →
   зелёной галкой (успех) или красным крестиком (ошибка).
3. Сборка идёт в два этапа: сначала `build-core` (ядро Xray-core,
   ~10-15 минут, самая долгая часть), потом `build-apk` (~3-5 минут).

Если нужно перезапустить сборку вручную (без нового коммита) —
в Actions есть кнопка **Run workflow** (сработает, так как в workflow
есть `workflow_dispatch`).

## Шаг 4. Скачать готовый APK

1. Открой завершившийся запуск в **Actions**.
2. Внизу страницы — раздел **Artifacts**.
3. Там будет **VlessHub-debug-apk** — жми, скачается zip с `.apk` внутри.
4. Распакуй и установи APK на телефон (Android спросит разрешение
   "установить из неизвестных источников" для браузера/файлового
   менеджера — это нормально для debug-сборки не из Google Play).

## Если сборка ядра (build-core) падает

Это самая хрупкая часть — `gomobile bind` иногда ломается из-за версий
Go/NDK/зависимостей апстрима AndroidLibXrayLite. Но я специально сделал
так, что **джоба build-apk не зависит от успеха build-core** (`if: always()`) —
APK всё равно соберётся и установится, просто без реального
VPN-туннелирования (в `XrayCoreBridge` пока заглушки). Кинь мне лог
ошибки из вкладки Actions — поправлю workflow под конкретную причину.

## Что делать дальше с обновлениями кода

Дальше, если попросишь у меня что-то доработать в коде — я обновлю файлы
здесь, пришлю обновлённый zip, и тебе нужно будет просто повторить
Шаг 2 (Upload files поверх существующих — GitHub спросит "Replace
these files?", подтверждаешь) — сборка перезапустится сама.
